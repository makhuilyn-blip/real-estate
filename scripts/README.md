# Singapore Property 101 — Short Video Scripts

Educational short-form video scripts (TikTok / Reels / Shorts) explaining Singapore real estate concepts in under a minute.

## Series format
- 40–55 seconds per video
- Structure: Hook (3s) → Setup → 2–3 key points → CTA
- Captions burned in (most viewers watch muted)
- Consistent "Singapore Property 101" branding/lower-third
- Pin a disclaimer comment on any script touching rates/eligibility, since these change over time
